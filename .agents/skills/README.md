# Neorism Skills

Короткие поведенческие скиллы для кэширования инструкций без технического шума:
- `canonical-backport`: Строгое копирование и адаптация кода из `reference/vampirism/`.
- `debug-logging`: Логгирование событий через `ModLogger` под флагами `Config`.
- `run-client-test`: Сборка (`.\gradlew assemble`), запрет дублей в `run/client/mods/`, проверка логов по запросу.
- `task-reporting`: Генерация отчетов (`DD-MM-YYYY-HH-MM-TITLE.md`) по git-истории строго по запросу пользователя.
